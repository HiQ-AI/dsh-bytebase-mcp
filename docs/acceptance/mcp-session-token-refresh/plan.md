# MCP 会话令牌刷新验收计划

## 症状与根因

凭据文件中的 Access Token 已刷新，但长连接 MCP 会话仍使用建连时的旧令牌，主会话和叶子会话均会在旧令牌到期后收到工具级 HTTP 401。

## 修复

- 在令牌到期前刷新全局 OAuth 凭据。
- 刷新成功后关闭旧 MCP 会话并重新建连、同步工具。
- 保留服务端未轮换的 Refresh Token。
- 连接销毁、异常重连时清理会话刷新计时器。

## 验证

1. 单元测试覆盖最小剩余有效期和 Refresh Token 保留。
2. MCP 集成测试覆盖登录、到期前刷新、会话重建和六个工具恢复。
3. 全量 `npm run check`。
4. 本地 Web profile 安装产物后验证哈希、运行态与两个只读 Bytebase 探针。

## 禁止事项

验收不创建 Issue/Plan/Rollout，不运行生产写 SQL，不改变既有业务授权范围。
